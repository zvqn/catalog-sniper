Catalog Sniper

Public Roblox catalog data for emotes, animations, and moods, served as paginated JSON.

Read the docs Repository

Catalog data and its search indexes are automatically synchronized through GitHub Actions. Full dataset files remain available for backwards compatibility.

Endpoints

All endpoints return JSON data and support standard CORS headers.

GET /api/emotes

Returns Roblox emote catalog data including assets, IDs, names, and descriptions with pagination and server-side search.

GET /api/animation

Returns Roblox animation catalog data and associated asset details, descriptions, pagination, and search.

GET /api/moods

Returns paginated Roblox mood catalog data for avatars.

GET /v1/info.json

Returns dataset metadata, count statistics, and last-synced timestamps.

Response Format

Each paginated endpoint accepts page (default 1), limit (default 50, maximum 200), and search. Search is case-insensitive across names and descriptions.

{
  "data": [
    {
      "id": 14618207727,
      "name": "Default Mood",
      "description": ""
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 94,
    "hasMore": true
  }
}

Examples

The complete Delta executor example is available in example.lua; it fetches pages from the API and can be connected to existing UI controls.

Fetch emote data

Run a paginated request from a Delta-compatible executor.

example.lua 
local HttpService = game:GetService("HttpService")
local url = "https://catalog-sniper.vercel.app/api/emotes?page=1&limit=50"
local response = HttpService:JSONDecode(game:HttpGet(url))

for _, emote in ipairs(response.data) do
    print(emote.id, emote.name, emote.description)
end
print(response.pagination.hasMore)
